## [업데이트 v0.0.1] - 2025-08-20

### 업데이트

- 🤖 **AI 답변 기능 안내**:
✨OpenAI의 최신 <strong>GPT-5 기반 KCD Assistant</strong>가 사용가능합니다.
더욱 향상된 문맥 이해와 정확도를 바탕으로 KCD 관련 질문에 대한 답변을 제공합니다.(답변 시간이 길어질 수 있습니다.)
빠른 속도를 원하시면 <strong>KCD Assistant(Google)</strong>를 사용해 주세요.
- 📁 **폴더 관리 및 맞춤형 프롬프트 기능 추가 안내**:
<strong>새 폴더 생성</strong>: 주제나 프로젝트 별로 대화를 생성하고 깔끔하게 관리할 수 있습니다.
<strong>맞춤형 시스템 프롬프트</strong>: 각 폴더에 특정 역할을 부여하는 시스템 프롬프트를 지정할 수 있습니다. 
예를 들어, "너는 유능한 KCD 전문가야"와 같은 규칙을 설정하면 해당 폴더 내 모든 대화에 자동으로 적용됩니다.
<strong>개인화된 지식기반</strong>: 사용자가 직접 지식 기반(노트) 및 파일을 업로드하여 AI가 답변 시 해당 내용을 참고하여 답변을 제공하도록 할 수 있습니다.
<strong>대화 분리 저장</strong>: 생성된 폴더별로 대화 기록이 독립적으로 저장되어 관리의 편의성을 높였습니다.
- 📝 **노트 기능 추가 안내**:
이제 사용자의 개인화된 지식베이스인 <strong>"노트"</strong> 기능을 사용할 수 있습니다. 
자주 사용하는 정보나 중요한 Q&A 내용을 저장해두고 빠르게 정보를 찾을 수 있습니다.(AI의 지식 기반으로 활용 가능)

## [업데이트 v0.0.0] - 2025-07-09

### 업데이트

- 🤖 **AI 답변 기능 안내**:
KCD Assistant: KCD 관련 자료에 기반하여 답변을 제공합니다.
암등록 Assistant: 암등록 관련 자료에 기반하여 답변을 제공합니다.
기타 Google, OpenAI의 AI도 사용 가능합니다. 질문하시기 전, 좌측 상단에서 이용하시는 AI의 종류를 선택해 주세요.
- 👍 **AI 답변 품질 평가 안내**: AI의 답변에 오류가 있거나 개선이 필요한 경우, 답변 하단의 평가 기능을 통해 피드백을 남겨주세요.  
여러분의 소중한 의견은 AI 성능 개선에 큰 도움이 됩니다.  
(※ 자세한 평가 방법은 좌측 사이드바의 #공지사항 채널을 참고해 주세요.)
- 🚫 **미지원 기능: ICD-9-CM(수술/시술 코드)**: 현재 ICD-9-CM 관련 질문은 지원되지 않습니다.  
해당 기능은 추후 업데이트를 통해 지원될 예정이오니, 이용에 참고 부탁드립니다.
- 🛠️ **웹사이트 테스트(베타) 운영 안내**: 현재 저희 웹사이트는 테스트(베타) 기간에 있습니다.  
이로 인해 일부 기능 사용 시 예기치 않은 오류가 발생할 수 있는 점, 너른 양해 부탁드립니다.😊
