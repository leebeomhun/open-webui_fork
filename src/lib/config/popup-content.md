## [업데이트 v0.0.3] - 2025-09-07

### 업데이트

- 🧠 **신규 AI 모델 추가: Auto & Thinking 모델**
✨ <strong>GPT-5-Auto, KCD Assistant(GPT-5-Auto)_test</strong>: 사용자의 질문 의도와 복잡성을 파악하여 최적의 추론 수준을 <strong>자동으로 조절</strong>하는 새로운 모델입니다. 이를 통해 간단한 질문에는 빠르고 간결하게, 복잡한 질문에는 깊이 있는 답변을 제공합니다.
    (※ KCD Assistant(GPT-5-Auto)_test 모델은 현재 테스트 중입니다.)
🤔 <strong>GPT-5-Thinking</strong>: 항상 높은 수준의 추론을 통해 <strong>상세하고 깊이 있는 답변</strong>을 제공하도록 설계된 모델입니다. 연구, 분석 등 전문적이고 자세한 정보가 필요한 사용자에게 최적의 경험을 선사합니다.

- 🔗 **인용 정보 확인 기능 개선**:
KCD Assistant 모델이 답변 생성 시 참고한 정보의 출처를 더 명확하게, 보기 쉽게 확인할 수 있도록 개선되었습니다.
이제 채팅 답변 하단의 <strong>"KCD 인용정보 확인"</strong> 버튼을 클릭하여 AI가 참고한 문서와 내용을 바로 확인해 보세요.

- 🧰 **KCD 자료 검색도구 사용 편의 개선**:
KCD 자료 검색도구가 활성화되면 입력창에 <strong>"KCD 자료 검색도구 사용중"</strong> 배지가 표시됩니다.
또한, 모델이 KCD 자료 검색도구를 지원하지만 선택되지 않은 경우 <strong>"KCD 자료 검색도구 사용추가"</strong> 버튼이 나타나며, 클릭 시 즉시 사용 도구에 추가됩니다.

기타 질문이나 개선 요청사항이 있으면 [카카오톡 오픈채팅방](https://open.kakao.com/o/gu1pKJdh)을 통해 알려주세요.

## [업데이트 v0.0.2] - 2025-08-28

### 업데이트

- 🚀 **KCD Assistant 기능 개선**:
✨<strong>지식기반 검색 속도가 향상되었습니다.</strong> 더욱 빠르게 관련 정보를 찾아 답변을 제공합니다.
AI가 지식기반을 참고하여 답변할 때는 채팅창에 <strong>스패너(<svg xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24" stroke-width="1.75" aria-hidden="true" stroke="currentColor" width="1em" height="1em" style="vertical-align:-0.15em; display:inline-block;"><path stroke-linecap="round" stroke-linejoin="round" d="M21.75 6.75a4.5 4.5 0 0 1-4.884 4.484c-1.076-.091-2.264.071-2.95.904l-7.152 8.684a2.548 2.548 0 1 1-3.586-3.586l8.684-7.152c.833-.686.995-1.874.904-2.95a4.5 4.5 0 0 1 6.336-4.486l-3.276 3.276a3.004 3.004 0 0 0 2.25 2.25l3.276-3.276c.256.565.398 1.192.398 1.852Z"></path><path stroke-linecap="round" stroke-linejoin="round" d="M4.867 19.125h.008v.008h-.008v-.008Z"></path></svg>) 아이콘</strong>의 활성 상태를 확인해 주세요.
스패너가 활성 상태가 아니라면 + 버튼을 눌러 활성 가능합니다(kcd-mcpo)

- 💡 **KCD Assistant 답변 정확도 향상을 위한 사용팁**:
불필요한 추가 텍스트 없이 <strong>진단명만 간결하게 입력</strong>하면 더 정확한 답변을 얻을 수 있습니다.
-예: "chemoport infection 진단 코드 알려줘" (❌) → <strong>"chemoport infection"</strong> (⭕)
여러 진단명을 한 번에 질문하는 것보다 <strong>하나씩 나누어 질문</strong>하는 것이 정확도를 높입니다.

- 📌 **자주 사용하는 모델 사이드바 상단 고정 기능**:
자주 사용하는 모델을 사이드바 상단에 고정하여 <strong>더 빠르고 편리하게 접근</strong>할 수 있습니다.
모델 선택기에서 고정하고 싶은 모델의 <strong>…(더보기) 버튼을 클릭</strong>한 후, <strong>"사이드바에 유지"</strong>를 선택하세요.

## [업데이트 v0.0.1] - 2025-08-20

### 업데이트

- 🤖 **AI 답변 기능 안내**:
✨OpenAI의 최신 <strong>GPT-5 기반 KCD Assistant</strong>가 사용가능합니다.
더욱 향상된 문맥 이해와 정확도를 바탕으로 KCD 관련 질문에 대한 답변을 제공합니다.(답변 시간이 길어질 수 있습니다.)
빠른 속도를 원하시면 <strong>KCD Assistant(Google)</strong>를 사용해 주세요.
- 📁 **폴더 관리 및 맞춤형 프롬프트 기능 추가 안내**:
<strong>새 폴더 생성</strong>: 주제나 프로젝트 별로 대화를 생성하고 깔끔하게 관리할 수 있습니다.
<strong>맞춤형 시스템 프롬프트</strong>: 각 폴더에 특정 역할을 부여하는 시스템 프롬프트를 지정할 수 있습니다. 
-예를 들어, "너는 유능한 KCD 전문가야"와 같은 규칙을 설정하면 해당 폴더 내 모든 대화에 자동으로 적용됩니다.
<strong>개인화된 지식기반</strong>: 사용자가 직접 지식 기반(노트) 및 파일을 업로드하여 AI가 답변 시 해당 내용을 참고하여 답변을 제공하도록 할 수 있습니다.
<strong>대화 분리 저장</strong>: 생성된 폴더별로 대화 기록이 독립적으로 저장되어 관리의 편의성을 높였습니다.
- 📝 **노트 기능 추가 안내**:
이제 사용자의 개인화된 지식베이스인 <strong>"노트"</strong> 기능을 사용할 수 있습니다. 
자주 사용하는 정보나 중요한 Q&A 내용을 저장해두고 빠르게 정보를 찾을 수 있습니다.(AI의 지식 기반으로 활용 가능)

### 업데이트

- 🤖 **AI 답변 기능 안내**:
KCD Assistant: KCD 관련 자료에 기반하여 답변을 제공합니다.
암등록 Assistant: 암등록 관련 자료에 기반하여 답변을 제공합니다.

해당 기능은 추후 업데이트를 통해 지원될 예정이오니, 이용에 참고 부탁드립니다.

이로 인해 일부 기능 사용 시 예기치 않은 오류가 발생할 수 있는 점, 너른 양해 부탁드립니다.😊
